# تصدير المخطط إلى Excel وإنشاء مخططات باستخدام Aspose.Slides

**إتقان تقنيات تصور البيانات مع Aspose.Slides for Java**

في المشهد القائم على البيانات اليوم، يعتبر *export chart to excel* برمجيًا مهارة يمكنها تحويل الأرقام الخام إلى قصص بصرية جذابة. سواء كنت تبني مجموعة شرائح تقرير أعمال أو لوحة تحكم تحليلات تفاعلية، يمنحك Aspose.Slides for Java القدرة على إنشاء وتخصيص وتصدير المخططات مباشرةً من الشيفرة الخاصة بك. في هذا البرنامج التعليمي ستتعلم كيفية إنشاء كائنات المخطط، وتصدير بيانات المخطط إلى Excel، وربط المخططات بملفات عمل خارجية لإدارة بيانات سلسة.

## إجابات سريعة
- **ما المكتبة المطلوبة؟** Aspose.Slides for Java (v25.4+).  
- **هل يمكنني تصدير بيانات المخطط إلى Excel؟** نعم – استخدم `readWorkbookStream()` واكتب البايتات إلى ملف *.xlsx*.  
- **ما إصدار Java المطلوب؟** JDK 16 أو أعلى.  
- **هل أحتاج إلى ترخيص؟** إصدار تجريبي مجاني يعمل للتقييم؛ يلزم ترخيص دائم للإنتاج.

## ما هو Aspose.Slides for Java؟
Aspose.Slides for Java هو API مكتوب بالكامل بلغة Java يتيح للمطورين إنشاء وتحرير وتحويل عروض PowerPoint دون الحاجة إلى Microsoft Office. يوفر مجموعة شاملة من الفئات لمعالجة الشرائح، وإنشاء المخططات، وتحويل الصيغ، مما يتيح حلول تقارير آلية. يدعم **50+ نوعًا من المخططات**، وربط بيانات كامل، وتصدير مباشر إلى Excel، مما يجعله مثاليًا لمشاريع **data visualization java**.

## لماذا تستخدم Aspose.Slides لإنشاء مخطط وتصديره إلى Excel؟
تصدير المخطط إلى Excel بسرعة وموثوقية. يزيل Aspose.Slides الحاجة إلى تثبيت Office، ويقدم **أكثر من 50 نمطًا مدمجًا للمخططات**، ويعالج العروض **حتى 300 ميغابايت في أقل من 30 ثانية** على عتاد الخادم القياسي. كما تحصل على إنشاء ملفات عمل Excel أصلية، مما يسمح للمحللين اللاحقين بالعمل مع الأرقام الخام دون نسخ‑لصق يدوي.

## دليل خطوة بخطوة

### كيفية إنشاء مخطط – تحميل عرض تقديمي
حمّل ملف PowerPoint موجود قبل أن تتمكن من إضافة أو تعديل المخططات.  
تمثل الفئة `Presentation` ملف PowerPoint في الذاكرة، وتكشف عن الشرائح والأشكال وكائنات المخطط.  
حمّل ملفك باستخدام `new Presentation("input.pptx")`، ثم اعمل مع الشريحة الأولى باستخدام `presentation.getSlides().get_Item(0)`. احرص دائمًا على استدعاء `presentation.dispose()` داخل كتلة `finally` لتحرير الموارد الأصلية.

### كيفية إنشاء مخطط – إضافة مخطط دائري إلى شريحة
أدرج مخططًا دائريًا، وهو مثالي لعرض البيانات النسبية.  
واجهة `IChart` هي نقطة الدخول الأساسية لتعامل مع المخططات؛ `addChart` تنشئ مخططًا جديدًا على الشريحة المستهدفة. قدم نوع المخطط (`ChartType.Pie`)، إحداثيات X/Y، والعرض/الارتفاع. بعد الإنشاء، يمكنك تخصيص العناوين، والأسطورة، وسلسلة البيانات عبر كائن `ChartData`.

### كيفية تصدير المخطط إلى Excel – تصدير بيانات المخطط
يسمح تصدير بيانات المخطط للمحللين بالعمل مع الأرقام في Excel، مما يتيح رؤى أعمق.  
`readWorkbookStream()` تُعيد ملف عمل Excel الأساسي للمخطط كمصفوفة بايت. استدعِ `chart.getChartData().readWorkbookStream()` لاسترجاع ملف العمل واكتب هذه المصفوفة إلى ملف باسم `externalWorkbook1.xlsx` باستخدام I/O القياسي في Java. يحتوي ملف Excel الناتج على البيانات الدقيقة المستخدمة في المخطط، جاهزًا لمزيد من التحليل.

### كيفية إنشاء مخطط – تعيين ملف عمل خارجي للبيانات الديناميكية
اربط مخططًا بملف عمل خارجي لتمكين تحديثات البيانات الحية دون إعادة بناء الشريحة.  
`setExternalWorkbook()` يربط المخطط بملف Excel خارجي لتحديثات البيانات الديناميكية. استخدم `chart.getChartData().setExternalWorkbook("externalWorkbook1.xlsx")` لربط المخطط بالملف الخارجي. عندما يتم تعديل ملف عمل Excel، يعكس المخطط التغييرات تلقائيًا في المرة التالية التي يتم فيها فتح العرض، مما يدعم سيناريوهات التقارير الديناميكية.

4. **تحليلات التسويق:** تصور مقاييس الحملات ومشاركة ملفات العمل القابلة للتعديل مع أصحاب المصلحة لاتخاذ قرارات تعاونية.

## المشكلات الشائعة وإصلاح الأخطاء
- **`FileNotFoundException`** – تحقق من أن `dataDir` يشير إلى مجلد صالح وأن مسار الإخراج قابل للكتابة.  
- **تسربات الذاكرة** – احرص دائمًا على استدعاء `presentation.dispose()` داخل كتلة `finally` لتحرير الموارد الأصلية.  
- **المخطط لا يظهر** – تأكد من أن فهرس الشريحة (`get_Item(0)`) يتطابق مع شريحة موجودة، وأن أبعاد المخطط ضمن حدود الشريحة.  
- **تصدير Excel ينتج ملفًا فارغًا** – تأكد من أن المخطط يحتوي فعليًا على سلاسل بيانات قبل استدعاء `readWorkbookStream()`.

```java
import com.aspose.slides.IChart;
import java.io.File;
import java.io.FileOutputStream;
import java.io.IOException;
import java.io.FileNotFoundException;
import com.aspose.slides.Presentation;

public class Feature3 {
    public static void main(String[] args) {
        // Set the path to your document directory and output directory
        String dataDir = "YOUR_DOCUMENT_DIRECTORY";
        
        Presentation pres = new Presentation(dataDir + "/presentation.pptx");
        try {
            // Access the first slide's chart
            IChart chart = pres.getSlides().get_Item(0).getShapes().addChart(
                com.aspose.slides.ChartType.Pie, 50, 50, 400, 600);
            
            // Define the path for the external workbook
            String externalWbPath = dataDir + "/externalWorkbook1.xlsx";
            File file = new File(externalWbPath);
            if (file.exists()) file.delete();
            
            // Export chart data to an Excel stream
            byte[] workbookData = chart.getChartData().readWorkbookStream();
            FileOutputStream outputStream = new FileOutputStream(file);
            outputStream.write(workbookData);
            outputStream.close();
        } catch (FileNotFoundException e) {
            e.printStackTrace();
        } catch (IOException e) {
            e.printStackTrace();
        } finally {
            if (pres != null) pres.dispose();
        }
    }
}
```
